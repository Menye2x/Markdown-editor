💾 How saving works

While you type, changes are autosaved after a short pause. The current session is kept in browser storage so refresh can restore the workspace.

  • Pause typing — the workspace autosaves.
  • Click away from the editor — the active file is saved.
  • Switch files — the previous file saves automatically.
  • Switch browser tabs / windows — pending edits save.
  • Ctrl+S (or ⌘+S) — saves all files with unsaved changes.
  • Refresh / reopen — the latest committed session is restored.

Deleted files never return after refresh: every state change is persisted synchronously to local storage, so the latest list (with deletions applied) is always what gets restored.
